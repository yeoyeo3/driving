# 운전면허 시각 오답노트

macOS Catalina 10.15.7 / Intel / Node.js 18용입니다. npm 패키지 설치 없이 동작합니다.
Vite는 현재 환경의 npm 네트워크 접근 제한으로 설치하지 않았습니다.
Node.js 18은 Catalina에서 실행 가능한 구버전이며 현재 지원이 종료된 버전입니다.

## 실행

터미널에서 아래 명령을 실행하고 창을 열어 둡니다.

```bash
cd /Users/apple/Documents/yeoyeo/driving
npm run dev
```

또는 Finder에서 `미리보기.command`를 실행합니다.

브라우저 주소창에 **http://127.0.0.1:5173** 을 입력합니다.
`오답노트.html`을 보여주며 HTML/CSS/JS 파일을 저장하면 자동 새로고침됩니다.
서버를 멈추려면 터미널에서 Ctrl+C를 누릅니다.
포트는 5173으로 고정되고, 같은 컴퓨터에서만 접속할 수 있습니다.

## 수정과 데이터

- 현재 학습 내용은 기존 `오답노트.html`과 Markdown 파일에 그대로 보존되어 있습니다.
- 서버는 파일을 읽기만 하며 학습 파일을 덮어쓰거나 초기화하지 않습니다.
- 자동 새로고침은 페이지 전체를 갱신하므로 펼친 정답 등 일시적인 화면 상태는 초기화됩니다.
- 메뉴·검색과 모의고사 답안·결과는 각 브라우저의 로컬 저장소에 보관합니다.
- 같은 기록을 보려면 같은 브라우저와 주소를 사용해야 합니다. 다른 기기나 GitHub Pages 주소로 자동 이전되지는 않습니다.

## 자동 갱신 확인

브라우저를 열어 둔 상태에서 `오답노트.html`의 문구를 수정하고 저장합니다.
새로고침 버튼을 누르지 않아도 변경 문구가 표시되어야 합니다.
원래 문구로 되돌려 저장해도 자동 반영됩니다.

## 아이폰에서 읽는 배포본

`npm run build`로 `_site` 폴더에 정적 웹사이트를 만듭니다. 학습 노트와 40문항의 정답·PDF 해설·보기별 보충 해설을 시험 시작 없이 읽을 수 있습니다.

개인 시험 점수·선택 답안·틀린 문항 목록은 브라우저에만 있어 배포본에 포함되지 않습니다. 배포본의 40문항 복습은 전체 해설이며, 개인 오답만 추린 기록으로 표시하지 않습니다.

GitHub 저장소 `yeoyeo3/driving`의 `main` 브랜치에 올리면 `.github/workflows/pages.yml`이 검사·생성·Pages 배포를 실행합니다. Pages가 아직 활성화되지 않았거나 계정 요금제에서 비공개 저장소 Pages를 지원하지 않으면 저장소의 **Settings → Pages**에서 설정을 확인해야 합니다. 저장소 공개 범위는 자동으로 바꾸지 않습니다.

예상 사이트 주소: `https://yeoyeo3.github.io/driving/` (Pages 배포 성공 후 사용 가능).

검사: `npm test`
